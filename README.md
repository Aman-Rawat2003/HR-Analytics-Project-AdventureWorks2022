# HR-Analytics-Project-AdventureWorks2022
SQL-based HR Analytics using the AdventureWorks2022 database. Developed 25+ advanced queries with CTEs and window functions to analyze employee demographics, attrition, tenure, and salary trends. Generated insights to support data-driven HR decisions and Power BI dashboard integration.

------------------------------------------------------------------------------------------------------------------------------
This project performs in-depth HR analytics using Microsoft SQL Server Management Studio (SSMS) and the AdventureWorks2022 dataset. It covers advanced querying techniques including CTEs, window functions, and aggregate analysis to extract meaningful insights into employee trends, attrition, and salary distribution. The output serves as a foundation for interactive Power BI dashboards that assist HR teams in workforce planning and retention strategies.
